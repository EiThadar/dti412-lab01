# Git Command Cheat Sheet
| Task | Command | Purpose |
|---|---|---|
| Check Git version | `git --version` | Show the installed Git version. |
| Configure name | `git config --global user.name "Ei Thadar Aung"` | Set the commit author name. |
| Configure email | `git config --global user.email "eithadaraung198@email.com"` | Set the commit author email. |
| Display configuration | `git config --list` | Show Git settings. |
| Clone repository | `git clone REPOSITORY-URL` | Download a repository to your computer. |
| Check status | `git status` | Show changed and staged files. |
| Add files | `git add .` | Stage changes in the current folder and its subfolders. |
| Commit changes | `git commit -m "message"` | Save staged changes in local history. |
| Upload changes | `git push` | Upload local commits to GitHub. |
| Download updates | `git pull` | Fetch and integrate remote changes. |
| View history | `git log --oneline` | Show a short list of commits. |
| Create branch | `git branch branch-name` | Create a new branch. |
| Switch branch | `git checkout branch-name` | Switch to another branch. |
| Merge branch | `git merge branch-name` | Merge a branch into the current branch. |
